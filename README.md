# 📖 [Budget app] <a name="about-project"></a>

The **Budget App** is a Ruby on Rails mobile web application where you can manage your budget: you have a list of transactions associated with a category so that you can see how much money you spent and on what.

## 🛠 Built With <a name="built-with"></a>

- **Ruby**: A dynamic, open source programming language with a focus on simplicity and productivity.
- **Ruby on Rails**: A server-side web application framework written in Ruby under the MIT License.
- **PostgreSQL**: A powerful, open source object-relational database system.
- **Visual Studio Code**: A free source-code editor made by Microsoft for Windows, Linux, and macOS.

## 💻 Getting Started <a name="getting-started"></a>

### Setup <a name="setup"></a>

To use this project. Clone this repository to your desired folder by:

- https://github.com/m00h0/Budget-app.git

### Prerequisites <a name="prerequisites"></a>

- Ruby
- Ruby on Rails
- PostgreSQL
- Git

### Install <a name="install"></a>

To install the project's dependencies, run:

```
bundle install
```

### Usage <a name="usage"></a>

To use, run:

```
rails server
or
rails s
```

### Run tests <a name="run-tests"></a>

To test, run:

```
bundle exec rspec
```
